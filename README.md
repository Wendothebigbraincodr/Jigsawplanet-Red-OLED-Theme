## How to Download

Download the RedTheme.js file above

## Usage

You'll need a userscript manager like [https://www.tampermonkey.net/](Tampermonkey) or [https://violentmonkey.github.io/](Violentmonkey). I personally use Violentmonkey as in my experience it works better on firefox, but the choice is up to you.
